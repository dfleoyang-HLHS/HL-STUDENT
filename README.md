# 花中學生來源分析

把國立花蓮高中三個年級的學生資料 Excel 整理成一份 `students.json`，再產生一個分析網頁 `index.html`。網頁可以查詢學生畢業國中的來源、報部身份，以及原住民族別。

- 資料範圍：2024、2025、2026 年入學（115 學年度的高三、高二、高一），共 998 人
- 線上網頁（私人連結，要分享請在網頁的「分享」選單開放權限）：<https://claude.ai/artifact/Wg4g1fRePdKaZaaZ7paT61>

## 快速開始

需要先安裝 [uv](https://docs.astral.sh/uv/)。在這個資料夾依序執行下面兩行：

```bash
uv run build_students_json.py   # Excel → students.json
uv run build_dashboard.py       # students.json → index.html
```

第一支程式會用 uv 自動安裝需要的 `openpyxl` 套件，不需要用 pip 另外安裝。Excel 更新後，重新執行這兩行即可。

## 資料夾內容

| 檔案 | 說明 |

| `高一學生資料一覽表_2026人學.xlsx`<br>`高二學生資料一覽表_2025入學.xlsx`<br>`高三學生資料一覽表_2024入學.xlsx` | 各年級學生名單，欄位有學號、座號、姓名、入學學校（即畢業國中） |
| `全校學生資料報部身份一覽表.xlsx` | 分頁報表，每頁開頭是班級代號，下面列出座號、學號、姓名、報部身份 |
| `原住民族別學生資料一覽表_YYYYMMDD.xlsx` | 欄位有學號、座號、姓名、原住民族別 |
| `build_students_json.py` | 讀取上面的 Excel，合併後產生 `students.json` |
| `students.json` | 整理好的學生資料，含姓名，**請勿公開** |
| `build_dashboard.py` | 讀取 `students.json`，把統計用的欄位嵌入網頁範本 |
| `index.template.html` | 網頁範本，要修改網頁請改這個檔案 |
| `index.html` | 產生出來的網頁，可以直接用瀏覽器開啟 |

### 檔名規則

程式是依檔名找到各個 Excel 的，新增或更換檔案時請遵守：

- 年級名單：`高?學生資料一覽表_西元入學年*.xlsx`。年級由檔名中的入學年推算。
- 報部身份：固定叫 `全校學生資料報部身份一覽表.xlsx`。
- 原住民族別：`原住民族別學生資料一覽表*.xlsx`。有多份時，使用檔名排序最後（日期最新）的那一份。

## students.json 結構

```jsonc
{
  "meta": {
    "school": "國立花蓮高級中學",
    "school_year": 2026, "school_year_roc": 115,
    "generated_at": "...",
    "source_files": ["..."],
    "total_students": 998,
    "class_types": {"10": "音樂班", "11": "數理資優班", "12": "體育班"},
    "moe_identity_counts": {"一般生": 767, "原住民生": 220, ...},
    "indigenous_tribe_counts": {"阿美族": 107, "太魯閣族": 61, ...},
    "notes": ["..."],
    "warnings": ["..."]          // 資料比對時發現的問題
  },
  "cohorts": [                    // 各年級摘要，依入學年排序
    {"entry_year": 2024, "entry_year_roc": 113, "grade": 3, "grade_name": "高三",
     "student_count": 337, "class_count": 12,
     "classes": [{"class_code": "301", "class_type": "普通班", "student_count": 30}, ...]}
  ],
  "students": [ ... ]             // 每位學生一筆，依年級（高三→高一）、班級、座號排序
}
```

### 學生欄位（students[]）

| 欄位 | 範例 | 說明 |
|---|---|---|
| `student_id` | `"310037"` | 學號 |
| `entry_year` / `entry_year_roc` | `2024` / `113` | 入學年（西元／民國） |
| `grade` / `grade_name` | `3` / `"高三"` | 年級 |
| `class_no` | `1` | 班序（1–12） |
| `class_code` | `"301"` | 班級代號 = 年級 + 兩位數班序 |
| `class_type` | `"普通班"` | 普通班、音樂班、數理資優班、體育班 |
| `is_special_class` | `false` | 是否為特殊班（第 10–12 班） |
| `seat_no` | `1` | 座號 |
| `name` | `"何彥澄"` | 姓名（原始欄位） |
| `name_zh` / `name_indigenous` | `"林宥漢"` / `"Utun･Aling"` | 姓名欄若是「漢名＋族名」，從第一個英文字母切開；沒有族名時 `name_indigenous` 為 `null` |
| `junior_high.code` | `"154506"` | 畢業國中代碼 |
| `junior_high.name` | `"花蓮縣立國風國中"` | 畢業國中校名 |
| `junior_high.county` | `"花蓮縣"` | 國中所在縣市（取校名前三字） |
| `junior_high.ownership` | `"公立"` | 公立、私立（含財團法人）、國立 |
| `identity_notes` | `[]` | 原始檔的身份註記欄，目前都是空的 |
| `moe_identity` | `"原住民生"` | 報部身份：一般生、原住民生、身心障礙生、身心障礙學生適性輔導安置 |
| `indigenous_tribe` | `"阿美族"` | 原住民族別；非原住民學生為 `null` |

## 資料處理規則

- **班級**：年級名單沒有班級欄位，程式依檔案列序推算：座號每次重新從 01 開始，就算下一班。推算結果已經和報部身份表上的正式班級代號逐筆比對，全部一致。
- **特殊班**：每個年級第 10 班是音樂班、第 11 班是數理資優班、第 12 班是體育班。設定在 `build_students_json.py` 的 `SPECIAL_CLASSES`。
- **跨檔比對**：報部身份和原住民族別都用學號對應，並檢查座號、姓名（報部身份表另外檢查班級代號）。程式也會確認「有族別」和「報部身份為原住民生」是否一致。對不上時會印出警告，並寫進 `meta.warnings`。目前的警告只有兩班座號跳號（高一第 12 班少 7 號、高三第 12 班少 4 號）。
- **學年度**：`build_students_json.py` 裡的 `CURRENT_SCHOOL_YEAR = 2026`，年級用它推算。**每年升級時請改成新的學年度**。

## 分析網頁

網頁有三個分頁，網址後面加上 `#special` 或 `#tribe` 可以直接開到對應的分頁。

1. **全校總覽**
   - 篩選：年級、班級、國中所在縣市、報部身份
   - 摘要數字、各國中來源人數長條圖（依年級分色）、縣市分布、公私立別、報部身份統計
   - 三屆逐校比較表：可以排序，含原住民生人數和「高一較高三」的增減
2. **特殊班分析**
   - 音樂班、數理資優班、體育班的摘要卡片
   - 特殊班與普通班的比較表：來源國中集中度、縣外比例、私立國中比例、原住民生比例
   - 所選班別的來源國中、縣市分布、報部身份，以及國中 × 班別交叉表
3. **原住民族別**
   - 各班別或各年級的族別組成（100% 堆疊長條圖和人數表）
   - 各族在各年級的人數變化（折線圖和表格，含「高一較高三」的增減）
   - 各族學生來自哪些國中（可選族別）、國中所在縣市、國中 × 族別交叉表
   - 圖上只替前五大族配色，其餘併為灰色的「其他族別」；表格和滑鼠提示會分開列出每一族

網頁只嵌入每位學生的年級、班級、畢業國中、報部身份、原住民族別，**不含學號和姓名**。篩選條件會記在瀏覽器裡，下次開啟時保留。

### 更新線上網頁

重新產生 `index.html` 後，線上版不會自動更新，需要再發布一次。可以請 Claude Code 把 `index.html` 重新發布到上面的連結。
